# 运行时验收、探索路由与排查路径

## 已验证

- CLI 初始化、双向索引、读取策略、标题树、主/子证据、确认归档和正文标题检索。
- GUI 回环状态、策略读写、同源限制、轮转和清理。
- 七日任务归档、ZIP/哈希清单、源清理、八周夹具的七周保留。
- HTTP 脱敏请求工具的成功、缺失秘密头、状态失败、文本断言失败、传输失败和临时响应清理。
- 带 UTF-8 BOM 的 `task.json` 可继续读取；现有 Skill 前言和 `plugin.json` 可解析。

## 变更

- 新增主任务 `path` 命令和 `path.json`，归档时折叠高价值终点与排除结论。
- 新增正式归档秘密检测；命中后不创建目标文档。
- 新增探索(Explore)路由，修复受控专题正文标题和路径元数据的候选检索。
- 标题树仅以同字符、长度不短于开围栏且后续只有空白的行结束代码围栏，避免围栏内短反引号泄漏标题。
- `http-check.sh` 拒绝通过普通 `--header` 传递 `Authorization`、`Cookie` 和常见令牌头；敏感值继续只从 `--secret-header` 的环境变量读取，调用方不得直接写入脚本参数。
- 退役 `bugfix` 的重复 Gotcha 导出脚本、派生索引和非生产 `example-skill`；保留原始示例材料与 `project-memory` 的唯一迁移工具。
