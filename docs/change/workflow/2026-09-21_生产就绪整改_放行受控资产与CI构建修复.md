# 2026-09-21 生产就绪整改：放行受控资产与CI构建修复

- 摘要: 优化根目录 .gitignore，移除对 docs/ 与受控规则资产的全局忽略，放行 docs/（包含 MEMORY.md、memory/、change/）与 .agents/AGENTS.md、.agents/gotchas.jsonl；隔离本地临时状态（/.agents/task-loop/ 等）；增强 tests/unit/records.test.js 针对空目录的防御性断言。
- 价值评估: high - 解决 GitHub Actions 干净 Runner 检出代码缺失受控记忆导致的 CI 失败问题，完善记忆完整性防御测试
- 有效性: active
- 关联专题: [workflow](../../memory/workflow.md)

---

#### 一、问题/需求

落实任务 `workflow-ci-gitignore-fix-01`：
1. GitHub Actions CI 全量构建失败：根目录 `.gitignore` 存在历史遗留规则 `/docs/*` 与 `/.agents/`，导致受控核心记忆（`docs/MEMORY.md`、`docs/memory/`、`docs/change/`）及 `.agents/AGENTS.md` 未被 Git 追踪；在干净的 GitHub Runner 上，`tests/unit/records.test.js:122` 测试当前工作区完整性时找不到 `docs/MEMORY.md`，返回 `status: "error"`，引发单测断言失败，随后的 `inspect` 与 `validate` 亦连带失败；
2. 需要确保受控资产被 Git 正常跟踪，同时隔离本地临时运行状态（`.agents/task-loop/`、`.agents/project-memory/`、`node_modules/`、`*.log`）；
3. 需要为 `tests/unit/records.test.js` 的 `checkIntegrity` 补充空目录或缺失主记忆时的防御性测试断言。

---

#### 二、原因分析

1. 历史配置在开发初期将 `/docs/*` 和 `/.agents/` 写入了 `.gitignore`，且 Git 规范规定父目录被排除后子文件无法再通过白名单重包含；
2. 开发者本地工作区存在未纳入 Git 的物理文件，导致本地单测通过而 CI Runner 缺少文件失败；
3. `records.test.js` 原有 `checkIntegrity` 测试仅断言当前仓库有效，未对缺失主记忆的异常分支编写防御性单元测试。

---

#### 三、测试结果

1. **.gitignore 优化**：
   - 彻底移除 `/docs/*` 与 `/.agents/`；
   - 明确放行 `docs/`、`.agents/AGENTS.md`、`.agents/gotchas.jsonl`；
   - 明确忽略 `/.agents/task-loop/`、`/.agents/project-memory/`、`/.agents/session/`、`node_modules/`、`*.log`；
   - 执行 `git status -s` 确认受控记忆与规则文件均处于可追踪识别状态，临时会话与任务状态被安全隔离。
2. **测试用例防御性增强**：
   - 在 `tests/unit/records.test.js` 中增加针对临时空目录缺少 `docs/MEMORY.md` 时的防御性断言，验证 `checkIntegrity` 准确返回 `status: 'error'` 并包含缺失主记忆错误信息。
3. **全量回归验证**：
   - `npm test`：74 个测试用例全部 PASS（Exit Code 0）；
   - `npm run inspect`：`integrity.status: valid`，0 错误 0 警告（Exit Code 0）；
   - `npm run validate`：项目级、全局级与兼容历史记录全部校验通过（Exit Code 0）。

---

#### 四、备注

1. **白名单约束**：严格限定在 `.gitignore`、`docs/**`、`.agents/AGENTS.md`、`.agents/gotchas.jsonl`、`tests/unit/records.test.js`、`docs/memory/workflow.md`、`docs/change/workflow/**` 授权范围内；
2. **零副作用**：保留对本地派单与任务运行时状态的忽略，不产生多余 Git 脏提交。
