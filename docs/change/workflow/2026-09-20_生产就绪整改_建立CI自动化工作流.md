# 2026-09-20 生产就绪整改：建立跨平台 CI 自动化工作流

- 摘要: 新增 .github/workflows/test.yml，配置覆盖 Linux/Windows/macOS 与 Node.js 20.x/22.x 的跨平台矩阵测试，自动运行单元测试套件、受控记忆完整性核验及双层 Gotcha 经验库校验。
- 价值评估: high - 完善 CI/CD 质量工程基建，确保跨平台与多版本 Node 兼容性及长期架构演进稳定性
- 有效性: active
- 关联专题: [workflow](../../memory/workflow.md)

---

#### 一、问题/需求

落实生产就绪整改方案 P0-2 & Issue 5（建立跨平台 CI 自动化工作流）：
1. 项目此前缺少标准 CI 工作流，代码质量与架构治理依赖本地手工命令核验；
2. 缺乏 Linux、macOS 与 Windows 跨平台环境及 Node 20/22 版本的自动化回归验证机制；
3. 需要将项目记忆三层完整性核验（`npm run inspect`）和经验库校验（`npm run validate`）纳入 CI 强门禁。

---

#### 二、原因分析

1. 工程基建演进滞后：早期处于单机开发与插件定义阶段，尚未建立远程仓库协作的 Actions 自动化工作流；
2. 多平台兼容风险：Windows 环境下路径处理与 Linux/macOS 存在斜杠和大小写差异，需通过多平台矩阵保证代码健壮性。

---

#### 三、测试结果

1. **工作流配置核验**：
   - 触发分支：`master`（覆盖 `push` 与 `pull_request`）；
   - 测试矩阵：`os: [ubuntu-latest, windows-latest, macos-latest]`，`node-version: [20.x, 22.x]`（共 6 组合）；
   - 执行步骤：`npm test`（原生单测）、`npm run inspect`（记忆完整性核验）、`npm run validate`（Gotcha 经验库校验）。
2. **本地等价验证**：
   - 本地依次执行三项命令全部顺利通过（`test`: 28 项单测全 pass；`inspect`: 状态 valid 0 错误 0 警告；`validate`: 8 条记录全部校验通过，Exit Code 0）。

---

#### 四、备注

1. **白名单约束**：严格限定在 `.github/workflows/test.yml`、`docs/memory/workflow.md` 与 `docs/change/workflow/**` 内实施；
2. **零依赖特性**：工作流无需执行 `npm install` 或下载外部三方依赖，充分利用 Node.js 原生能力，运行速度极快且环境隔离性强。
