# 2026-09-21 生产就绪整改：补充插件市场清单文件 (Marketplace Manifest)

- 摘要: 新增仓库根目录 marketplace.json 与 .claude-plugin/marketplace.json 标准市场清单文件，解决在客户端“添加插件市场”时提示找不到清单的问题，确保包结构符合规范；与前序 .gitignore 及完整性防御单测保持协同一致。
- 价值评估: medium - 满足客户端安装与插件市场直接索引的标准清单要求，提升生态接入能力
- 有效性: active
- 关联专题: [workflow](../../memory/workflow.md)

---

#### 一、问题/需求

落实任务 `workflow-ci-and-marketplace-manifest-01`：
1. 用户在客户端使用“添加插件市场 (Add Marketplace)”功能输入 `https://github.com/JHJ1848/jiaohuan-dev` 时报错：`"Marketplace manifest not found in git repo: https://github.com/JHJ1848/jiaohuan-dev.git"`；
2. 原因是客户端在通过 Git 仓库地址添加市场时，需要在仓库根目录寻找 `marketplace.json`（或 `.claude-plugin/marketplace.json`）；
3. 需要按规范补齐清单文件，并确保前序修复的受控记忆放行规则与单测全量通过。

---

#### 二、原因分析

1. 项目此前仅维护了 `package.json` 与各技能自身 `SKILL.md`，缺少 Claude Code 插件市场标准的根级清单描述文件 `marketplace.json`；
2. 导致客户端在拉取仓库时无法解析插件元数据。

---

#### 三、测试结果

1. **清单文件创建**：
   - 创建 `marketplace.json`（仓库根目录）与 `.claude-plugin/marketplace.json`（统一规范目录）；
   - 包含标准 `$schema`、`name: "jiaohuan-dev"`、`description`、`owner` 及 `plugins` 数组配置。
2. **Git 可见性与忽略隔离核验**：
   - 执行 `git status -s`：`marketplace.json` 与 `.claude-plugin/marketplace.json` 均处于 Git 可追踪状态。
3. **全量回归验证**：
   - `npm test`：74 个测试用例全部 PASS（Exit Code 0）；
   - `npm run inspect`：`integrity.status: valid`，0 错误 0 警告（Exit Code 0）。

---

1. **白名单约束**：严格限定在 `marketplace.json`、`.claude-plugin/**`、`.gitignore`、`docs/**`、`.agents/AGENTS.md`、`.agents/gotchas.jsonl`、`tests/unit/records.test.js`、`docs/memory/workflow.md`、`docs/change/workflow/**` 授权范围内；
