# 2026-09-21 生产就绪整改：精简去CI与通用市场结构重构

- 摘要: 响应用户最高指令，精简去除非必要的测试套件与 CI 工作流（移除 .github/ 与 tests/，移除 package.json 中的 scripts.test），杜绝提示词插件过度工程化；重构通用市场与单插件安装清单（规范 plugin.json 与双路径 marketplace.json），并清理无引用孤儿历史图片。
- 价值评估: high - 剥离过度工程化测试套件，降低维护负担，提升在各大厂商客户端通过 GitHub 仓库地址直接添加市场或安装单插件的通用兼容性
- 有效性: active
- 关联专题: [workflow](../../memory/workflow.md)

---

#### 一、问题/需求

落实任务 `workflow-marketplace-restructure-and-ci-removal-01`：
1. 用户明确指出当前项目主要以提示词及轻量运行时为主，过多复杂测试套件与 CI 会带来过度工程化负担，要求移除 test 程序与 CI；
2. 规范采用市场最通用的 plugin 文件结构，支持各大厂商直接通过 GitHub 仓库地址安装集成（同时支持添加插件市场与添加单插件两种模式）；
3. 清理项目中无引用的历史遗留孤儿文件。

---

#### 二、原因分析

1. 早期阶段构建了过多针对底层 Node.js 脚本的单测与 CI 矩阵，违背了提示词与技能插件轻量敏捷的本质定位；
2. 缺乏标准单插件元数据配置（`plugin.json` 字段不全），限制了第三方客户端直接拉取该仓库作为独立插件的能力。

---

#### 三、测试结果

1. **去 CI 与精简化**：
   - 彻底删除 `.github/` 目录及其下的工作流 `workflows/test.yml`；
   - 彻底删除 `tests/` 目录；
   - 更新 `package.json`：移除 `scripts.test`，保留受控记忆检验 `inspect` 与经验库检验 `validate`。
2. **通用市场与插件结构标准化**：
   - 更新根目录 `plugin.json`：补充完整标准字段（`name: "jiaohuan-dev"`, `version: "1.0.0"`, `description`, `author`, `skills: "./skills"`, `keywords`, `license`），支持单插件直接安装；
   - 维护根目录与 `.claude-plugin/` 目录双路径 `marketplace.json`，支持作为插件市场添加。
3. **孤儿残留清理**：
   - 删除未引用的历史图片：`skills/bugfix/image-20260724162754884.png`、`skills/project-memory/image-20260724170922748.png`。
4. **治理核验回归**：
   - `npm run inspect`：`integrity.status: valid`，0 错误 0 警告（Exit Code 0）；
   - `npm run validate`：项目级、全局级与兼容历史记录全量校验通过（Exit Code 0）。
