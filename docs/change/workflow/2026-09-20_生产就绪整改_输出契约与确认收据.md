# 2026-09-20 生产就绪整改：输出契约校验器与确认收据防自我授权门禁

- 摘要: 新增 skills/workflow/schemas/ 下机器可读 Schema（workflow-decision.schema.json, bugfix-report.schema.json），实现 contract.js 契约校验器与 confirmation.js 防伪确认收据生成与验证器（防篡改、防过期、范围边界比对），并编写专项单元测试与四大主链路确定性评测。
- 价值评估: high - 确立 Workflow 机器可读标准输出规范，引入防模型自我授权的强安全确认收据门禁与评测闭环
- 有效性: active
- 关联专题: [workflow](../../memory/workflow.md)

---

#### 一、问题/需求

落实生产就绪整改方案 Phase 3（P1-3, P0-6）：
1. Workflow 决策与 Bugfix 修复报告缺乏机器可读契约与 Schema 定义，跨模块调用缺乏结构化保障；
2. 缺乏防模型自我授权机制，模型在缺少明确用户授权时可能越权生成写操作；
3. 需要为工作流四大主链路（dev, bugfix, read-only bugfix, explore）提供确定性路由与输出结构评测体系。

---

#### 二、原因分析

1. 早期语义路由主要依靠纯文本 Markdown 阐述，容易因模型自由发挥产生字段漏缺或格式漂移；
2. 执行授权未绑定带签名的时效性收据凭证，无法从密码学与路径范围上杜绝模型绕过授权修改关键系统代码。

---

#### 三、测试结果

1. **Schema 与契约校验落地**：
   - `workflow-decision.schema.json` 规范定义 `route`, `reason`, `scope`, `next_gate`, `risk` 字段；
   - `bugfix-report.schema.json` 规范定义 `root_cause`, `reproduction`, `fix_boundary`, `evidence` 字段；
   - `contract.js` 实现 `validateDecision` 与 `validateBugfixReport` 零依赖原生校验。
2. **确认收据防自我授权与越界拦截**：
   - `confirmation.js` 实现 `issueReceipt` 与 `verifyReceipt`，集成 SHA-256 签名计算（绑定任务、范围、过期时间与 salt），支持超时阻断（`Expired`）、篡改阻断（`Tampered`）与越界写入阻断（`OutOfScope`）。
3. **测试与评测覆盖**：
   - `tests/unit/contract.test.js`：覆盖契约校验与确认收据全生命周期安全场景（11 个用例全部通过）；
   - `tests/agent-evals/routing.test.js`：覆盖四大主链条（dev、bugfix、只读诊断、explore）确定性路由与契约评测（4 个用例全部通过）；
   - 执行 `npm test`：全套 64 个测试用例全部 PASS（Exit Code 0）。

---

1. **白名单约束**：严格限定在 `skills/workflow/schemas/**`、`skills/workflow/scripts/**`、`tests/unit/contract.test.js`、`tests/agent-evals/**`、`docs/memory/workflow.md` 与 `docs/change/workflow/**` 授权范围内；
2. **零依赖与可移植**：全部基于 Node.js 原生 crypto 与 path，不引入外部依赖。
