# 运行时路由与排查路径设计

**状态：** 已在隔离样例验收。  
**范围：** 不增加调度器、持久状态机、向量检索或第二索引。

## 决策

- `workflow` 在当前上下文按语义选择开发、诊断、修复或探索；语义不清进入只读探索(Explore)。路由不授予修改权限。
- `path.json` 位于主任务临时目录，仅保存节点摘要、父节点、状态、证据引用和结论。子智能体(Agent)只写草稿。
- 正式场景(Scene)仍是六段。归档时只把已证实/已实施终点和有结论的已排除节点压缩到“已证实事实与证据”、路径摘要和检索词。
- `memory-get` 仍从受控 `MEMORY.md` 索引开始；索引标签未命中时，仅检查已登记文档的标题和受控元数据。
- `put` 在任何正式目标创建前扫描待写字段和受管草稿。疑似凭据必须人工脱敏，运行时不自动替换。

## 验收边界

隔离样例已覆盖路径节点、归档、关键词回查和秘密拒绝。真实业务环境的权限、接口和数据契约不在本次证明范围。
