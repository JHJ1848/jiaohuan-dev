# 诊断(Debug)

遵从 `../../rules/engineering-principles.md`，只读取证，不编辑代码或正式记录。非平凡诊断必须先读 `references/diagnosis-playbook.md`。

- 建立场景-目标卡，按影响分流；先查外部环境、数据、调用链、日志、Git、change 和记忆，每轮只验证一个假设。
- 主任务用 `path` 记录已证实、已排除、待确认和已实施节点及证据引用；不写原始思维链。异步智能体(Agent)只交 `draft`。
- 接口证据使用最小请求卡和“写入 -> 读取 -> 断言”。真实请求须用户授权；敏感请求头用 `--secret-header` 环境变量，输出只保留脱敏状态和断言。
- 输出根因或未知项、不变量、影响范围和最小计划。业务含义或计划不清时回到探索(Explore)；计划确认后交 `dev`。
