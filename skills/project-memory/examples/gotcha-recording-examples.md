# 遗留陷阱迁移示例

边界：本文件只作为遗留陷阱(Gotcha)的一次性迁移输入，不参与主链检索或建立平行索引。迁移后归入场景(Scene)的固定六段合同；第六段陷阱(Gotcha)内容可空，无则写“无”。

## 示例：状态门禁导致列表为空

原始陷阱摘要：列表为空时，先核对真实请求、权限、上级状态和数据记录；不要先修改页面展示。

迁移为场景(Scene)时，写入：

1. `#### 场景与目标`：说明入口、角色、状态、异常表现和不变量。
2. `#### 已证实事实与证据`：列出请求、代码位置、数据查询或日志的精确引用，并标注待复核项。
3. `#### 处理与决策`：说明根因判断、候选方案及被否定方案。
4. `#### 结果与验证`：记录实际结果；未实测时明确写“未实测”。
5. `#### 边界与未知`：说明未改范围、风险和仍需确认的业务含义。
6. `#### 陷阱(Gotcha)`：写“不要将空列表直接归因于前端；先确认状态门禁”，无可复用内容则写“无”。

旧条目不作为新的权威事实；迁移后的场景(Scene)应标明来源、复核状态和替代关系。
