# 记忆归档(Memory Put)

按 `../../rules/engineering-principles.md` 归档；先读 `references/archival-contract.md`。任务结束不自动归档；未获确认先询问，再做价值评估。

- 主任务把证据、决策和候选记录放入 `temp/<task>/`；主任务唯一维护 `path.json`。子智能体(Agent)只交草稿。
- 正式 `put` 只接受受管临时证据和 `docs/` 目标；场景(Scene)使用既有六段，路径摘要只进入“已证实事实与证据”、摘要和检索词。
- 归档前扫描正式字段和受管草稿。命中令牌、密码、Cookie、授权头、JWT 或常见密钥特征时拒绝归档，要求人工脱敏；不自动掩盖。
- 只沉淀可复用事实、决策和已排除路径；不保存原始思维链。陷阱(Gotcha)是场景(Scene)第六段。
- 输出价值评估、目标、合并/替代结果、临时材料状态和全部实际“记忆引用”。
