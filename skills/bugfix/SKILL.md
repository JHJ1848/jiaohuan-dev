# 缺陷修复 (Bugfix)

遵循 `rules/engineering-principles.md`。本技能是 `workflow` 的兼容入口，完整闭环链路为：

`memory-get -> debug -> dev -> code-review -> memory-put`

## 触发条件
- 出现编译报错、运行时异常、数据不一致或接口偏差，需要排障与修复闭环。

## 执行步骤
1. **诊断阶段 (`debug`)**：遵循 `<外部环境 -> 数据 -> 调用链/代码>` 顺序，结合 Git 历史还原意图，产出已确认根因与最小修复方案。
2. **确认门**：修复方案与影响范围必须获用户明确确认，严禁盲目修改。
3. **修复阶段 (`dev`)**：实施最小可逆代码修改，运行本地验证并确保 Exit Code 0。
4. **审查阶段 (`code-review`)**：实施变更后必须执行代码审查，检查规范与回归风险。
5. **归档阶段 (`memory-put`)**：审查通过后向用户申请四段式变更记录归档。

## 停止条件
- 修复中发现新异常或范围扩大时，立即停止修改并回退至 `debug` 重建计划。
